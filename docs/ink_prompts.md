# 水墨/古风素材提示词库（课文古风模板）

> 配套 `renderer/public/ink/` 与 `tools/ink_asset_check.py`。
> 每个素材位一块，块内**通用 + 正面 + 反向**齐全，可直接整块复制去生成。
> 出片后必须过 `ink_asset_check.py` 的 6 项判据才允许入库。

## 素材位对照

| 位 | 作用 | 缺失时 | 现有 |
|---|---|---|---|
| `open` | 开场底（墨滴入纸） | 退成程序化墨滴 | `ink_drop_bloom.mp4` ✅ |
| `reveal` | 正文揭示底（雾散/水波） | 退成软边墨晕遮罩 | — |
| `bg` | 正文底（远山/竹林/江面） | 退成纯纸面 | `ink_misty_mountains.mp4` ✅ |
| `mid` | 中段空镜/转场 | 整段跳过 | `ink_splash_transition.mp4` ✅ |
| `end` | 落款底（空白宣纸） | 退成纯纸面 | — |
| `tex` | 纸纹叠加 | 退成 SVG 程序纹理 | — |

## ① 开场 open

```
【通用提示词】
竖版 9:16，分辨率 1080×1920，帧率 24fps，时长 10 秒（取前 8 秒）；
底为手工宣纸（handmade Chinese xuan paper），暖白偏米色，纤维纹理细密均匀，纸面平整铺满整个画面直到四边；
水墨写意，单色墨（焦墨到淡墨自然过渡），可极少量朱红点缀；
固定机位完全锁定，无推拉摇移；光线均匀柔和，纸面明亮（不要压暗、不要黑背景、不要暗角）；
画面中不得出现任何文字、汉字、字母、数字、水印、印章文字、人手、人脸、毛笔实物。

【正面提示词】
ink_drop_bloom（已有）—— 墨滴入纸晕染
一滴浓墨从画面上方垂直落入宣纸中央，接触瞬间迅速向四周晕开，墨色边缘呈毛边羽化状，中心深黑、外圈渐淡为半透明浅灰；墨晕扩张时伴随极细水痕不规则蔓延，随后墨色在纸上缓慢渗开变淡；纸面纤维清晰可见。

ink_brush_touch_v1 —— 笔尖触纸起笔
一支毛笔的笔尖（只出现笔锋，不出现笔杆与手）从画面上方落下，笔尖触纸瞬间墨汁洇开成一小团墨点；笔锋随即轻轻提离，墨点继续在纸上缓慢扩散，边缘呈羽状毛边；纸面纤维纹理清晰，墨色由浓到淡自然过渡。

ink_line_wander_v1 —— 墨线游走
一条浓墨线条在宣纸表面缓慢游走延伸，起笔浓重收笔渐淡，边缘毛糙有飞白；行进时在纸面留下细微洇染痕迹，转折处墨色略深；线条路径舒展不规则，像写意笔法在纸上行走。

【反向提示词】
文字, 汉字, 字母, 数字, 水印, 印章, 毛笔笔杆实物, 人手, 人脸, 骷髅, 彩色, 高饱和, 蓝色, 绿色, 紫色, 黑背景, 暗角, 重暗角, 强烈对比, 硬边缘, 叶脉纹理, 叶片, 血管, 硬切, 频闪, 快速闪烁, 镜头移动, 推拉, 摇镜, 3D 渲染, 卡通, 插画
```

## 五个必须压的坑

| 坑 | 表现 | 提示词里必须写的 |
|---|---|---|
| 纸出成叶子 | 背景像枯叶/叶脉 | `手工宣纸、纤维细密均匀铺满到四边`；反向词加 `叶脉纹理, 叶片, 血管` |
| 晕染太生硬 | 墨块边界像硬切 | `边缘极度羽化、半透明、不规则毛边` |
| 画面压太黑 | 水墨变黑底片，叠字看不清 | `纸面明亮、留白充分`；反向词加 `黑背景, 暗角` |
| 死片 | 整段几乎不动 | 必须让「雾在动/水在动/墨在扩散」，帧差 ≥1.0 才算过 |
| 出成横版带黑边 | 上下黑边，裁完变形 | 设置里选 9:16；**别在提示词里写分辨率数字指望它生效** |

## 出片后校验

```bash
$PY tools/ink_asset_check.py /path/to/新素材.mp4
```

6 项：规格（9:16、≥4s、≥24fps）· OCR 有字直接 FAIL · 墨色中位饱和 ≤25 · 帧差 ≥1.0 · 无黑边 · 循环首末相似 ≥0.6。

已入库三条实测参考值：`ink_drop_bloom` 帧差 5.96 / 饱和 29；`ink_misty_mountains` 帧差 2.01 / 上三分之一亮度 193；`ink_splash_transition` 帧差 11.28 / 末帧亮度 9.7。
