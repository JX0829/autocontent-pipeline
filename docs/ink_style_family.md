# 水墨片模板 · 素材池与风格包

> 分支：`feature/textbook-story` · 建立日期：2026-11-16 · 负责人：小何

## 一、为什么要有这一层

原有 9 套「模板」实测只改配色与圆角（每套 preset 1.3–1.7KB，字段仅
`accentPrimary / canvasBg / cardBorder / barRadius / ambientGlow`），
跨视频画面相似度 dHash 均值 0.62、同模板 0.71–0.81 —— 属于平台判定的
「换汤不换药」。差异化必须在**呈现骨架**层面发生，而不是调色板。

水渍片这一族采用两层结构：

```
素材位（slot）    —— 内容可替换，换素材不改代码、不改排版
风格包（stylepack）—— 换包即换气质（配色/字体/转场/装饰），代码零改动
```

## 二、素材位（6 类视频位 + 2 类静帧位）

| 位 | 作用 | 缺失时 |
|---|---|---|
| `open` | 开场底（墨滴 / 泼墨 / 笔尖触纸 / 墨线游走） | 程序化纸面 + 墨滴动画 |
| `reveal` | 正文揭示底（云雾散 / 水波荡 / 帘幕掀 / 烟丝升） | 软边径向墨晕遮罩 |
| `bg` | 正文底（远山 / 竹林 / 江面 / 窗棂 / 雪庭） | 纯纸面 |
| `mid` | 中段空镜（竹叶 / 墨滴飞溅 / 飞鸟 / 落花 / 香烟） | 整段跳过 |
| `end` | 落款底（空白宣纸 / 残墨晕痕 / 折痕旧纸） | 纯纸面 |
| `tex` | 纹理叠加（宣纸纤维 / 绢帛 / 旧纸黄斑 / 竹简竖纹） | SVG turbulence 程序生成 |
| `seal` | 印章图（PNG 透明） | 程序化朱红方印 |
| `audio` | BGM / 环境音 | 静音 |

组合数（仅视频位）：`open 4 × reveal 4 × bg 5 × mid 5 × end 3 × tex 4 = 4800`。

## 三、组合引擎规则

1. **可复现**：以 `run_id` 为种子选取，同一 run 重渲染结果完全一致。
2. **反重复**：同一 slot 的同一素材连续 ≤2 条；整组组合最近 10 条内不重复。
3. **落盘审计**：实际使用的组合写入 `material_binding.json`（与
   `src/utils/material_binding.py` 的物料绑定同源），可复核。
4. **缺素材降级**：池子不足时自动程序化兜底，不阻塞出片。

## 四、风格包（stylepack）字段

```yaml
name: ink_wash
palette:   { paper: '#EFE6D4', ink: '#1C1A17', accent: '#A6261F' }
font:      { title: STKaiti, body: STKaiti }
transition: ink_bleed      # ink_bleed | paper_wash | crossfade | hard_cut
ornament:  { seal: program, border: none, kicker: horizontal }
assets:    { open: ..., reveal: ..., bg: ..., mid: ..., end: ..., tex: ..., seal: ..., audio: ... }
```

预设包：

| 包 | 气质 | 配色 | 适用题材 |
|---|---|---|---|
| `ink_wash` | 古雅素净 | 宣纸米白 + 焦墨 + 朱砂 | 古诗、课文、文化人物 |
| `ink_night` | 冷峻夜色 | 深墨底 + 银灰墨 + 暗红 | 历史事件、悬疑、战争 |
| `ink_vermilion` | 节庆民俗 | 朱砂红 + 墨黑 + 金 | 年俗、节令、民俗 |

## 六、客观验收门禁

| 检查 | 工具 | 门槛 |
|---|---|---|
| AI 素材合规 | `tools/ink_asset_check.py` | 无文字(OCR conf≥78)、中位饱和 ≤40、帧差 ≥1.0、无黑边 |
| 画面有动 | 帧差能量（0.5s 采样） | 全片均值 ≥3.0；任一 2s 窗口不得全静止 |
| 文字不截断 | `InkTextLayout` 静帧量墨迹边界框 | 四周留白 ≥60px、无触边；竖排区高 > 宽 |
| 转场平滑 | 亮度曲线单步跳变 | ≤20/0.2s；无黑场（最暗帧 >120） |

## 七、踩坑记录（务必保留）

1. **`writing-mode: vertical-rl` 在 headless Chrome 的 flex 容器里会塌成 0 宽高**，
   文字整段不渲染（实测 still 输出空白）。改用 `flexDirection: column` 逐字堆叠，
   视觉等价且稳定。
2. **不要把每个字做成独立容器再横向排列**：视觉上变成横排单字列，
   且被 flex 挤压（62px 字号挤到 44px 列宽）后字被裁切。
   正确做法：一句一个容器，字在里面纵向堆叠。
3. **VText 必须 `flexShrink: 0`**，否则多列诗句被压缩导致文字变形/截断。
4. **泼墨硬转场太突兀**：亮度从 21 直落 9 会像黑场硬切。改为
   「上一幕淡回纸面 → 下一幕径向软边墨晕化开」，单步亮度跳变 28 → 18，
   最暗帧 9 → 165。
5. **AI 素材常见缺陷**：Gemini 会把竖版内容塞进 16:9 画布并补黑边（实测某条
   1920×1080 里内容只占中间 640px、68.3% 像素纯黑）——必须裁切后再用。
