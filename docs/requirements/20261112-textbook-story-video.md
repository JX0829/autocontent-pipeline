# 需求梳理：跟着课文看历史（暂定名）

> 提出人：用户｜梳理：小品（产品）｜日期：2026-11-12｜状态：需求分析，待决策

---

## 一、一句话定义

**把小学语文课本里的每一篇课文，变成一支「课文背后的故事」短片**：
诗/文写的是什么 → 作者当时经历了什么 → 那个时代发生了什么 → 为什么这几句能流传下来。

不是朗读，不是讲解，是**故事片**。

---

## 二、为什么要做（机会判断）

1. **内容存量天然巨大且不用追热点**：小学 1-6 年级教材内古诗文约百余篇（需按教材版本核对），每篇都能独立成片，可排期数月，完全不依赖每日速报。
2. **搜索需求常青**：家长辅导、老师备课、孩子背诵，是全年稳定需求，寒暑假/开学季有峰值。
3. **和现有能力高度复用**：物料 → LLM 分镜 → TTS 配音 → Remotion 渲染 → 双模态 → 三平台发布，这条链路已经跑通并有 20+ 条实拍验证。
4. **差异化**：市面上同类内容大多是「朗读 + 课件式讲解」，**用电影的讲法讲背景**（作者处境、时代、命运转折）是明显空位。

---

## 三、目标用户（决定语调与时长，必须先定）

| 用户 | 他们想要什么 | 对我们的要求 |
|---|---|---|
| **A. 小学生（8-12 岁）** | 好懂、不枯燥、能记住 | 语言浅、节奏快、画面吸引人、3 分钟内 |
| **B. 家长（辅导者）** | 孩子愿意看 + 考试用得上 | 知识点准确、有考点提示、可反复看 |
| **C. 语文老师（备课）** | 课堂导入素材 | 史实严谨、有出处、可截取片段 |

**建议主攻 A+B**（家长替孩子找内容，是实际的内容消费决策者）；C 作为口碑扩散人群。

---

## 四、内容形态决策（需要拍板）

### 4.1 时长
- 现有流水线：`scenes` 硬约束 **3~8 镜**，成片 25~35 秒 → **做不了故事**
- 建议：**90~150 秒**（约 12~25 镜），符合「中视频」区间，B站/视频号友好，抖音也能吃
- 代价：分镜 schema、TTS 对齐、渲染时长都要放宽——这是**必须改流水线**的地方

### 4.2 平台与画幅
- 竖屏 9:16 → 抖音/视频号（主阵地，家长手机端消费）
- 横屏 16:9 → B站（老师、深度用户）
- 现有双模态能力直接复用

### 4.3 视觉风格（最大缺口）
- 现有模板全部是**科技风**（深色底、卡片、等宽字体）
- 需要新增：**水墨/宣纸底色、竖排书法标题、古地图/卷轴转场、史料质感纹理**
- 画面素材来源三种方案（见 §7）

## 五、单篇内容结构（内容配方）

以《示儿》（陆游，五年级）为例：

| 段落 | 时长 | 内容 | 情绪 |
|---|---|---|---|
| 1. 钩子 | 0-10s | 「这首诗，是一个 85 岁老人临终前写的最后 28 个字」 | 悬念 |
| 2. 原诗 | 10-25s | 全诗上屏 + 一句白话拆解 | 沉静 |
| 3. 作者处境 | 25-60s | 陆游一生：生在北宋灭亡那年，一辈子主张北伐，被贬、被弃用，临终仍未见收复 | 压抑 |
| 4. 时代背景 | 60-100s | 靖康之变 → 南宋偏安 → 主和派当道，讲清「北定中原」四个字有多重 | 悲愤 |
| 5. 回扣 | 100-130s | 「家祭无忘告乃翁」——他连死后都要知道结果 | 高潮 |
| 6. 落点 | 130-150s | 这首诗为什么进了课本：它写的不是爱国口号，是一个人的一辈子 | 余味 |

**固定模板**：钩子 → 原诗 → 作者 → 时代 → 回扣 → 落点。
好处：可批量、可质检、观众形成预期。

## 六、内容准确性红线（教育类，容错极低）

这是**和现有科技速报最大的差异**——科技新闻说错一句，评论区纠正；课文说错一句，孩子记一辈子。

1. **史实必须有出处**：作者生卒、事件年份、官职变迁，必须来自可核查来源（中华书局/上海古籍等权威版本、教材注释），不能靠模型记忆
2. **不确定就模糊表达**：史料有争议处（如某些诗歌的确切创作年份）必须写「一般认为」「据记载」，禁止编造细节
3. **不能在史实里加戏**：可以渲染情绪，但不能虚构对话、虚构场景里的人物行为
4. **教材版本标注**：以人教部编版为准，片尾标注「课文出处：部编版小学语文 X 年级 X 册」
5. **AI 生成标注**：按《人工智能生成合成内容标识办法》，画面为 AI 生成需标注
6. **人工终审**：每条片子在发布前必须过一道**事实核对**（谁来做？见 §10 决策点）

## 七、画面素材方案（三选一或组合）

| 方案 | 做法 | 成本 | 风险 |
|---|---|---|---|
| A. 纯文字动画（现有能力） | 大字 + 转场 + 纹理底 | 最低，今天就能做 | 90 秒全是字，留不住孩子 |
| B. AI 生成插画 | 每镜生成古风画面 | 中，需统一画风 prompt + 一致性控制 | 人物/服饰易出错（唐宋混穿），需审图 |
| C. 公有领域素材 | 古画、文物图、博物馆开放资源 | 低，但要逐张核对授权 | 与内容匹配度靠人工挑 |

**建议**：MVP 用 **A+C**（文字 + 公有领域古画/文物图），V2 上 B（AI 插画），并要求画风锁死（同一套 prompt 前缀 + 参考图）。

---

## 八、产能规划

- 单篇生产周期（当前人工介入下）：物料 20 分钟 + 渲染 20 分钟 + 审核 15 分钟 ≈ 1 小时/篇
- 若做 **每周 3 篇**：约 3 小时/周，可持续
- 存量：百余篇古诗文 ≈ 8-10 个月内容储备（按每周 3 篇）
- **不建议**一次性批量生产，宁可边发边调（画风、节奏、时长都要靠数据验证）

---

## 九、分阶段落地

### MVP（2 周内可验证）
- 选 **5 篇**最具故事性的课文（如《示儿》《闻官军收河南河北》《出塞》《石灰吟》《七步诗》）
- 画面：文字 + 公有领域素材，**不做 AI 插画**
- 时长：90 秒左右，12 镜左右
- 只发 **视频号**（家长人群最集中），跑数据
- 验收标准：完播率 > 35%、平均观看 > 45 秒

### V2（MVP 达标后）
- 上 AI 古风插画，画风统一
- 开放到 B站 + 抖音
- 建立「课文库 → 物料」半自动生成（人工只做事实核对）

### V3
- 批量覆盖 1-6 年级，按学期节奏排期（开学季集中上古诗单元）
- 考虑做成系列合集（B站专栏/播放列表），沉淀搜索流量

## 十、需要你拍板的 5 个决策点

1. **账号归属**：新开一个教育号，还是在现有科技号里混发？
   - 建议：**新号**。科技号受众和内容调性会被稀释，且算法标签会乱
2. **主攻人群**：小学生 / 家长 / 老师（建议 A+B）
3. **时长**：90 秒（快节奏）还是 150 秒（讲得透）
4. **事实核对谁来做**：我（小品）做初核 + 你终审？还是引入第三个人/agent？
5. **第一批做哪 5 篇**：我建议《示儿》《闻官军收河南河北》《出塞》《石灰吟》《七步诗》——都有强烈的个人命运 + 时代冲突

## 十一、风险清单

| 风险 | 影响 | 应对 |
|---|---|---|
| 史实错误 | 教育内容口碑崩塌，不可逆 | 强制出处 + 人工终审 + 争议处模糊表达 |
| 视觉同质化/塑料感 | 留不住人，尤其孩子 | 画风锁死 + 真实材质纹理（Hallmark 体系） |
| 现有 scenes 3-8 限制 | 技术上做不了 90 秒 | 需改流水线 schema（交小何） |
| AI 插画人物考据错误 | 被专业用户指错（唐宋服饰混用） | 每朝代建服饰参考库，或关键人物用剪影/背影 |
| 教材版本差异 | 用户说「我们课本不是这样」 | 片尾固定标注版本，文案避免「唯一正确」表述 |
| 与现有速报抢产能 | 两条线互相拖累 | 速报优先，课文片按周固定排期 |

## 十二、复用 vs 新建（给技术的口径）

| 环节 | 现状 | 结论 |
|---|---|---|
| 物料 JSON → LLM 分镜 | ✅ 已有 | 复用，需换 SYSTEM_PROMPT（故事叙事版） |
| TTS 配音（edge-tts） | ✅ 已有，音色可配 | 复用，需选「讲述感」音色与语速 |
| Remotion 渲染双模态 | ✅ 已有 | 复用组件骨架 |
| 视觉模板 | ❌ 全科技风 | **新建古风/水墨模板** |
| scenes 3-8 限制 | ❌ 硬约束 | **需放宽到 25 镜** |
| 三平台发布 | ✅ 已有 | 复用 |
| 事实核对 | ❌ 无 | **新增强制环节** |
