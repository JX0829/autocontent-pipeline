# 课文背后 · 古风视觉规格 v1.0（M2 设计输入）

| 项 | 内容 |
|---|---|
| 服务对象 | `feature/textbook-story` · M2 古风模板（R：小开 / A：小何） |
| 编写 | 小品（PM，视觉决策 R/A） |
| 日期 | 2026-11-12 |
| 本轮范围 | **只做出片 + 视觉切题**；5 篇篇目、发布账号、发布验收一律搁置 |
| 样片基准 | `materials/20261112_textbook_shier.json`（《示儿》，120s / 14 镜） |

> 一句话设计意图：**观众第一眼要认出「这是古人的东西」，第二眼要认出「这是给今天的孩子看的」**。宁可素，不可花；宁可留白，不可堆料。

---

## 一、五条总原则（先立规矩，再谈细节）

1. **反塑料感**：不要纯黑（#000）与纯白（#FFF）、不要渐变霓虹、不要玻璃拟态阴影。所有底色都是有纤维的纸，所有文字都是被墨写下的。
2. **无科技语义**：画面里不得出现终端绿、代码等宽字体、数据图表、UI 卡片、进度条、坐标网格。**这是硬性判据，不是审美偏好。**
3. **一屏一义**：每镜只讲一件事。需要并列两个信息时用「史料卡」，不叠加。
4. **动效克制**：全片转场类型 ≤ 3 种，无快切、无闪白、无弹跳缩放、无粒子。动效只用于「翻纸、卷轴、落笔」这三类物理动作。
5. **留白即节奏**：安全区内文字占版面积 ≤ 55%，其余留给纸纹与墨晕。留白是长短句之间的呼吸。

## 二、配色（Design Tokens，可直接落进 preset）

### 2.1 主色板

| 语义 | Token | 色值 | 用量上限 | 说明 |
|---|---|---|---|---|
| 宣纸底（主） | `paperBase` | `#F2E9D8` | 画面 60~80% | 米黄宣纸，暖而不甜 |
| 宣纸底（次） | `paperDeep` | `#E6DAC3` | ≤ 25% | 做明暗分区/卡片底 |
| 墨（主文字） | `inkPrimary` | `#1C1A17` | — | 近墨不近黑，正文实测对比度 14.4:1 |
| 墨（次） | `inkSecondary` | `#3A3532` | — | 注释、副标题 |
| 墨（淡） | `inkMuted` | `#6B6259` | — | 出处、页码、片尾小字 |
| 朱印（强调） | `vermilion` | `#B23A2E` | **画面 ≤ 8%** | 只用于印章、关键年份、强调一字 |
| 赭石（辅助） | `ochre` | `#8C6A3F` | ≤ 12% | 地图山体、卷轴边、木轴 |
| 石青（辅助冷） | `mineralBlue` | `#4A6472` | ≤ 10% | 江河、夜间场景的冷调 |
| 淡金（点缀） | `paleGold` | `#C8A05A` | ≤ 3% | 仅卷轴轴头、年份数字描边 |

### 2.2 对比度实测（WCAG，脚本计算，非估算）

| 前景 | 对 `paperBase #F2E9D8` | 对 `paperDeep #E6DAC3` | 可否承载文字 |
|---|---|---|---|
| `inkPrimary` | **14.40:1** | 12.55:1 | ✅ 正文/标题 |
| `inkSecondary` | 10.04:1 | 8.75:1 | ✅ 副标题 |
| `inkMuted` | 4.95:1 | 4.32:1 | ⚠️ 仅限 ≥28px 小字注释 |
| `mineralBlue` | 5.19:1 | 4.52:1 | ⚠️ 仅限标注/地名 |
| `vermilion` | 4.92:1 | 4.29:1 | ⚠️ 仅限朱印反白、单字强调 |
| `ochre` | 4.10:1 | 3.57:1 | ❌ 只做图形（山体/木轴） |
| `paleGold` | 2.02:1 | 1.76:1 | ❌ 只做细线点缀，禁写字 |

**规则**：`ochre` 与 `paleGold` 一律不得承载任何文字；需要文字的地方只能用 `ink*` 三色。

### 2.3 硬性禁用色

- `#000000` / `#FFFFFF` 大面积填充（真需要纯黑只允许用于墨色文字描边 ≤ 1px）
- 任何饱和度 > 85% 的荧光色（`#00E5FF`、`#39FF14`、`#FF2D55` 一类）
- 紫蓝渐变、玻璃高光、外发光（`box-shadow` 带色晕）

### 2.4 纸纹与墨晕（基底必需，不可省）

- **纸纹**：一张 1080×1920 / 1920×1080 的石宣纸纹理，`opacity 0.06~0.10`，`mix-blend-mode: multiply`，**固定不动**（镜头切换时纸纹不动，画面才有「同一张纸」的连续感）
- **墨晕**：段落起始处一枚柔边径向墨点，`blur 40~70px`，`opacity 0.10`，随转场淡入淡出
- **四边压暗**：`vignette` 遮罩，边缘压暗 12%，避免平得像 PPT

## 三、字体与竖排规则

### 3.1 本机实况（已实测，非假设）

```text
/System/Library/Fonts/Supplemental/Songti.ttc  ← 唯一可用的中文宋/楷类字体
可用字族：Songti SC（Regular / Light / Bold / Black）、STSong、宋体-简
不可用：楷体（Kaiti / STKaiti）、魏碑、隶书 —— 本机一律未安装
```

### 3.2 字体栈（按此顺序声明，缺字自动降级）

| 用途 | 首选（需引入） | 本机可用回退 | 字号（竖屏 1080×1920） | 横屏等比 ×0.72 |
|---|---|---|---|---|
| 书法标题 | `LXGW WenKai`（霞鹜文楷，OFL 开源） | `Songti SC` Bold | 96~120 | 70~86 |
| 竖排原文 | `LXGW WenKai` / `Songti SC` Regular | `Songti SC` Regular | 72~84 | 52~60 |
| 正文/叙述 | `Songti SC` Regular | 同 | 44~52 | 32~38 |
| 出处/角标 | `Songti SC` Light | 同 | 30~34 | 22~24 |
| 字幕 | `Songti SC` Regular（**禁 900 粗体**） | 同 | 36~40 | 28~32 |

- **字体加载**：`LXGW WenKai` 须下载 `LXGWWenKai-Regular.ttf` / `-Bold.ttf` 放 `renderer/public/fonts/`，用 `@font-face` + `staticFile()` 加载；**不得依赖系统字体**（否则换机渲染会漂移）。
- **禁用**：`Inter`、`Menlo`、`JetBrains Mono` 等无衬线/等宽字体在本模板内**一律不得出现**（当前 `SafeAreaContainer` 的默认字体栈是科技风，古风模板必须覆盖它）。
- **字距**：标题 `letter-spacing: 0.06em`；竖排原文 `0.18em`；正文 `0.02em`。
- **行距**：正文 `1.7`；史料卡 `1.5`；竖排按列间距处理，不用 line-height。

### 3.3 竖排原文规则（`vertical_poem` 专用）

```css
writing-mode: vertical-rl;
text-orientation: upright;
font-variant-east-asian: traditional;  /* 有繁体字形时用繁体，与古画气质一致 */
```

- **版心从右起**：首列右边缘贴安全区右边界（竖屏 `x = 984`），逐列向左排。
- **单列字数**：竖屏 ≤ 14 字/列，横屏 ≤ 10 字/列；七绝 28 字 → 竖屏 2 列、横屏 3 列。
- **列宽** = 字号 + 字距 + 12px 间隙；列间不加竖线（不要网格感）。
- **标点**：保留全角标点，交给浏览器处理竖排标点位置；渲染后必须人工看一次，若逗号错位则改为「每句一列、句末不加标点」。
- **落款/印章**：诗末左下角一枚朱印（方形 56~72px，`vermilion` 底 + 纸色反白字，内容如「课文背后」四字），距末列 ≥ 40px，**不与正文重叠**。
- **整屏可读时长**：竖排原文必须单独停留 ≥ 4.5s；七绝按 2.5 字/秒 慢读，约 11~12s（与物料 `script.poem.sec` 对齐）。

## 四、版式安全区（精确坐标，直接按此实现）

### 4.1 竖屏 1080×1920（抖音/视频号）

| 区域 | 坐标 | 说明 |
|---|---|---|
| 内容安全区 | `x 96 → 984`（宽 888），`y 214 → 1540`（高 1326） | 沿用现有 `SafeAreaContainer` 校准值，**不改** |
| 系列角标 | `y 214 → 268`，左对齐 `x 96` | 「课文背后 · 第 1 篇」小字 30px，`inkMuted` |
| 标题/原文主区 | `y 300 → 1380` | 实际文字块垂直居中于该区间 |
| 字幕区 | `y 1560 → 1660`（`bottom 260~360`），宽 ≤ 888，居中 | **必须从现在的 `bottom 40` 抬上来**，否则被抖音评论区遮挡 |
| 片尾标识 | `y 1720 → 1800`，右对齐 `x ≤ 984` | 「画面 AI 生成 · 课文出处：部编版五上」，30px `inkMuted` |
| 禁放区 | `x > 984`（右侧图标列）、`y > 1660`（评论/文案区） | 不得放任何正文 |

### 4.2 横屏 1920×1080（B站）

| 区域 | 坐标 | 说明 |
|---|---|---|
| 内容安全区 | `x 260 → 1660`（宽 1400），`y 100 → 980`（高 880） | 沿用现有横屏值 |
| 系列角标 | `y 100 → 150`，左对齐 `x 260` | 24px |
| 标题/原文主区 | `y 180 → 860` | 竖排原文列宽固定在最右 2~3 列，右边缘 `x ≤ 1600` |
| 字幕区 | `bottom 110`（`y 900 → 970`），宽 ≤ 1400 | **不得贴底**，避开 B站进度条与弹幕输入区 |
| 片尾标识 | 右下 `x ≤ 1660`，`y 940 → 980` | 24px |

### 4.3 双模态一致性

- 竖屏与横屏**共用同一套 tokens、同一套组件**，仅坐标按 4.1/4.2 切换（横屏不得另做一版视觉）。
- **首帧 0.5s（15 帧 @30fps）封面海报**：竖屏与横屏都内嵌，横屏必须是独立 16:9 版式（`BilibiliCoverStill`），**严禁把竖版封面拉伸/裁切塞进横屏**；首帧海报不加字幕、不加片尾标识。

## 五、转场与节奏

| 层级 | 手段 | 时长 | 允许次数 | 禁止 |
|---|---|---|---|---|
| 段内（镜与镜） | 墨晕叠化（cross-dissolve + 纸纹不动） | 24 帧（0.8s） | 不限 | 位移滑入、缩放弹跳、闪白闪黑 |
| 段间（六段之间） | 卷轴推入/推出（`scroll_transition`） | 36 帧（1.2s） | ≤ 5 次 | 单镜内使用卷轴 |
| 文字入场 | 淡入 / 笔锋擦出（mask 从左到右） | 18 帧（0.6s） | 不限 | 逐字打字机（像终端）、弹字 |
| 文字出场 | 淡出 | 12 帧（0.4s） | 不限 | 翻转、碎裂、粒子 |

- **单镜时长**：8~10s（120s / 14 镜 = 8.6s，符合 M1 断言区间）。
- **镜内节奏**：入场 0.6s → 稳定 ≥ 6.5s → 出场 0.4s。**稳定段不得再动**（古画挂在墙上是静的）。
- **禁止快切**：任一镜 < 4s 视为不合格（除片头 0.5s 封面帧）。
- **音频**：古琴/箫环境音，`-20dB`；音效仅三种——翻纸（`page_turn`）、落笔（`brush_down`）、印章（`seal_press`），单次 < 0.6s，**不得使用 whoosh 转场音、电子 ding**。
- **字幕**：逐句同步，单屏 ≤ 20 字，120ms 淡入淡出；**去掉现有 `▸` 前缀与 900 粗体**，不加发光/描边。

## 六、visual_type 定义：适用条件 / 禁用条件

> 本轮新增 5 类，与科技风 4 类（`terminal_code` / `ui_card` / `stat_chart` / `media_showcase`）**并列共存、互不复用**；古风模板内前 3 类科技视觉为**非法值**，渲染层应直接断言失败而非静默回退。

### 6.1 `ink_title` 水墨标题

| 项 | 内容 |
|---|---|
| 用途 | 段1 钩子、段6 落点、系列片头 |
| 版式 | 标题 1~2 行，每行 ≤ 12 字，居左或居中；标题下方一枚朱印；背景为纸纹 + 墨晕 |
| 动效 | 笔锋擦出 0.6s → 静止 |
| 适用 | 一句话主张（“他写下最后二十八个字”） |
| **禁用** | 需并列 ≥ 2 条信息（改用 `archive_card`）；标题含数字列表；与竖排原文同屏（同一镜只能有一个主角） |

### 6.2 `vertical_poem` 竖排原文

| 项 | 内容 |
|---|---|
| 用途 | 段2 原诗（全片 1~2 次，七绝 1 次足够） |
| 版式 | 竖排右起，单列 ≤14 字（竖屏）/ ≤10 字（横屏）；末列左下朱印；旁侧可挂一句 8~14 字白话小注（`inkMuted`，横排，不压诗行） |
| 动效 | 整块淡入 0.8s，列内不逐字动画；停留 ≥ 4.5s |
| 适用 | 全文 28 字以内的近体诗 |
| **禁用** | 诗句 > 40 字（改分两镜）；含异体字且未校对（竖排最容易被认错）；同屏再挂字幕段落 |

### 6.3 `ancient_map` 古地图

| 项 | 内容 |
|---|---|
| 用途 | 段4 时代背景中涉及地理/战线时（如“靖康之变 · 宋室南渡”“北定中原”） |
| 版式 | 示意性山水舆图：墨线山川 + `mineralBlue` 江河 + `ochre` 山体 + 若干州府墨点与地名小字；**无经纬网、无比例尺、无卫星底图** |
| 动效 | 地图整体缓慢横移 2~4%（Ken Burns 级别，120 帧内不超 4%）；路线用虚线墨痕逐步画出（≤ 2s） |
| 适用 | 有真实迁徙/战线/都会位置信息的段落 |
| **禁用** | 原文无地理信息时硬凑；画现代国界/今省界（涉政治边界争议，一律不画）；画精确兵力部署（史实无法核实）；与 `stat_chart` 同镜（禁止把丢失州府数量做成柱状图） |

### 6.4 `archive_card` 史料卡

| 项 | 内容 |
|---|---|
| 用途 | 段3~5 的年份、官职、文献引用、生卒 |
| 版式 | 一张纸色卡片（`paperDeep`），最多 3 条，每条：`关键年份/词` + 一行 ≤ 18 字陈述；左缘一道 2px 赭石竖线；卡片右下角标出处小字（`inkMuted` 28px） |
| 动效 | 卡片淡入 + 轻微上移 8px（0.5s）；条与条之间 0.3s 依次出现 |
| 适用 | 需要「可核查感」的信息陈列 |
| **禁用** | 超过 3 条（拆镜）；做成表格/进度条/百分比（那就变成数据图表了）；把整段旁白原样搬进卡片（旁白归字幕，卡片只放关键信息） |

### 6.5 `scroll_transition` 卷轴转场

| 项 | 内容 |
|---|---|
| 用途 | 六段之间的段落切换 |
| 版式 | 上下木轴（`ochre`）+ 纸面自右向左展开；轴头淡金细线；展开完成后轴体可留在画面上沿 0.5s 再淡出 |
| 动效 | 36 帧（1.2s）完成展开；不得加速/回弹 |
| 适用 | 段界（钩子→原诗、原诗→作者、作者→时代、时代→回扣、回扣→落点） |
| **禁用** | 段内镜头切换；连续两次紧邻使用（间隔 ≥ 2 镜）；作为片头开场第一帧（首帧必须是封面海报） |

### 6.6 允许保留的 `media_showcase`（严格限定）

若使用公有领域古画/文物图（需求文档 §7 方案 C）：

- 必须是公有领域或开放授权素材，`materials.images` 记录来源与授权；
- 画面右下角 24px 小字标注「图源：XX」；
- 不得裁掉人物面部、不得加滤镜改色、不得叠加科技感边框。

## 八、视觉验收清单（我用这 8 条验收样片，逐条给结论）

| # | 判据 | 通过标准 | 方式 |
|---|---|---|---|
| 1 | 零科技风 | 画面无终端绿/代码框/数据图表/UI 卡片/网格背景 | 逐帧看片 + 抽帧比对 |
| 2 | 古风成立 | 纸纹可见、字为宋/楷、有朱印、无纯黑纯白大块 | 抽帧 |
| 3 | 竖排正确 | 右起、单列 ≤14 字、标点不错位、朱印不压字 | 抽帧放大 |
| 4 | 安全区 | 字不出 `x 96~984 / y 214~1540`；字幕在 `bottom 260~360`；标识在 `y 1720~1800` | 叠安全区框截图 |
| 5 | 双模态 | 1080×1920 与 1920×1080 各一版，横屏非拉伸 | `ffprobe` + 看片 |
| 6 | 转场克制 | 全片 ≤ 3 种转场；无闪白、无快切、无弹跳 | 看片 |
| 7 | 朱色用量 | 朱色面积 ≤ 8%，无第二处高饱和色 | 抽帧取色统计 |
| 8 | 合规标注 | 片尾「画面 AI 生成 + 教材出处」，横竖屏都有 | 看片尾帧 |

> 任一条不通过 → 打回，写明「第 N 条不达标 + 帧号」，不整片重做。

## 九、与科技链路的隔离要求（供小何评审口径）

- 实现方式：新增 `renderer/src/templates/presets/ink_story.ts` + 5 个 `Ink*View.tsx` 组件；注册表新增 `ink_story`，`DEFAULT_THEME_TO_TEMPLATE` 新增 `'textbook-story' → 'ink_story'`。
- **不得修改**：`editorial_news` / `cupertino_glass` / `notion_craft` / `linear_obsidian` / `cyber_blueprint` / `matrix_hud` / `solarized_amber` / `swiss_vanguard` 任一 preset 的 tokens；不得改 `terminal_code` / `ui_card` / `stat_chart` / `media_showcase` 四个 View 的默认渲染分支。
