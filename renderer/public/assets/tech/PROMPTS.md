## 6. 已知坑

| 坑 | 说明 |
|---|---|
| 写字要求 | AI 写不清公式/汉字，`数学公式` 只能要求「快速流动、轻微失焦、仅作光效纹理」，绝不能要求清晰字符 |
| 骷髅/骨骼 | 侧脸或人形轮廓必须写「纯轮廓、内部镂空、无五官、无骷髅、无骨骼」，否则出成骷髅头 |
| 黑边 | 横版素材会被裁出黑边，`verify_assets` 会拦；优先出 9:16 |
| 静止 | 提示词写「镜头锁定」但要有光在动，全静止的素材出片会被判「死片」（帧差 <1） |
| 暖色 | 科技类统一冷色；暖橙只作点缀（如颅内光），大面积暖色会与模板冷调打架 |
